# Cryptocurrency Price Tracker

## Overview
A Python application that fetches real-time cryptocurrency prices using the CoinGecko API.

## Features
- Fetch live cryptocurrency prices
- Search cryptocurrencies by name
- Parse JSON responses
- Handle invalid inputs and network errors

## Technologies Used
- Python
- Requests
- CoinGecko API
- JSON
- Git & GitHub

## Installation

```bash
pip install requests
```

## Output
The application displays the current price of the entered cryptocurrency in USD.
